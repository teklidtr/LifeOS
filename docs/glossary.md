# Glossary

**Canonical vault:** Markdown files that remain the primary human-readable source of truth.

**Registry:** Deterministic metadata about files, hashes, provenance, ownership, proposals, tasks, and graph state.

**Proposal:** A durable, reviewable description of consequential changes.

**Managed block:** A marked region that an authorized generator may replace.

**Generated view:** A rebuildable dashboard, index, report, or log.

**Context pack:** Question-specific evidence assembled for an agent.

**Structural graph:** Relationships explicitly or deterministically derived from vault data.

**Inferred graph:** Candidate semantic relationships generated by an agent or graph backend.

**Rolling-wave planning:** Keeping distant goals broad while detailing only near-term work.

**Daily menu:** A small set of worthwhile actions matched to time, energy, motivation, and recovery.

**Export profile:** Rules selecting and transforming content for a specific consumer.
