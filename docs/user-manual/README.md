# LifeOS User Manual

This manual explains how to install, understand, and use LifeOS as a private,
Obsidian-native system for knowledge, study, adaptive planning, personal
observation, and agent-assisted reflection.

7. [Troubleshooting, Upgrades, and Removal](07-troubleshooting.md)
8. [Adaptive Planning and Feedback](08-adaptive-planning.md)

## Suggested reading path

New users should read Chapters 2, 4, and 5 first. Chapter 1 is useful when you
want to understand the system boundaries, while Chapter 3 is the reference
chapter for individual modules.
