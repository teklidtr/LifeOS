# LifeOS Vision

## Purpose

LifeOS is a private, Obsidian-native system combining knowledge management, study, flashcards, goals, adaptive planning, habits, health metrics, journals, and personal reflection.

It should help the user observe:

- how energy and motivation change
- which environments and task shapes work
- why plans fail or succeed
- how goals evolve
- which sources and methods produce durable understanding
- which personal interpretations are supported, contested, or premature

## Design posture

LifeOS should be human-readable, inspectable, reversible, incrementally buildable, useful before it is complete, tolerant of incomplete knowledge, and strict about consequential mutation.

## Non-goals

LifeOS is not:

- a corporate productivity dashboard
- a system that turns every interest into an obligation
- a fully autonomous agent that rewrites the vault
- a giant universal ontology
- a replacement for Obsidian
- a second canonical database of personal knowledge
- a system that presents correlations as causes

## Core loops

```text
capture
  ↓
deterministic registration
  ↓
semantic interpretation
  ↓
proposal
  ↓
human approval
  ↓
validated application
  ↓
useful views and reflection
```

```text
long-term direction
  ↓
medium-term outcome
  ↓
near-term actions
  ↓
daily menu matched to current capacity
  ↓
result and observation
  ↓
plan improves
```
