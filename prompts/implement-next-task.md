# Implement the Next LifeOS Task

1. Read `AGENTS.md`.
2. Read the architecture and decisions relevant to the next ready task.
3. Select exactly one task from `tasks/ready/`.
4. Move it to `tasks/in-progress/`.
5. Implement only its scope.
6. Run all validation.
7. Record discovered work under `tasks/backlog/`.
8. Move the task to `tasks/completed/` only when all criteria pass.
9. Do not silently alter architecture, policy, or neighboring subsystems.
