# LifeOS Bootstrap

This repository is the implementation scaffold for a private, Obsidian-native LifeOS.

LifeOS combines durable knowledge management, study and flashcards, adaptive planning, journals, habits, health metrics, personal observation, proposal-based agent edits, deterministic provenance, and optional Graphify-assisted relationship analysis.

Its purpose is to help the user understand how they work, not merely maximize task completion.
