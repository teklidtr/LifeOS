# Objective

# Dependencies
None.

# Scope
Inspect the current migration version and add the next migration, expected to be version 2.
Create `proposals` table:
```sql
CREATE TABLE proposals (
    id TEXT PRIMARY KEY NOT NULL,
    status TEXT NOT NULL,
    title TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```
Add index:
```sql
CREATE INDEX proposals_status_idx ON proposals(status);
```
Update `REQUIRED_TABLES` or equivalent registry schema validation.
Do not make SQLite stricter than the canonical proposal loader through complex timestamp `CHECK` expressions.
If the existing migration framework is forward-only, do not invent down migrations.
