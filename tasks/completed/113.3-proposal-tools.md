# Objective
Implement the `ingestion.create_wiki_proposal` facade tool that allows an external AI agent to generate draft proposals safely via MCP, enforcing the trust boundary without any embedded AI dependency.

# Scope
- Implement one tool descriptor: `ingestion.create_wiki_proposal`.
- Set effect to `ToolEffect.PROPOSAL_PRODUCING`.
- Define immutable, provider-independent request and result models (`CreateWikiProposalRequest`, `CreateWikiProposalResult`).
- Verify registered/unchanged status of the source.
- Delegate proposal creation safely without directly exposing core domain SQLite rows.
- Define a LifeOS-owned generator identity (`lifeos.facade.external_agent`).
- Implement facade error mapping hierarchy for all ingestion orchestrator errors.

# Implementation Options
Use Option B: Compose source verification, `build_wiki_proposal()`, and `persist_wiki_proposal()` directly, bypassing `AnalysisBackend` entirely.

# Trust Boundary
- **Agent provides only**: `source_path`, `target_path`, `title`, `body`.
- **LifeOS verifies/generates**: source state, raw-byte hash, proposal ID, canonical timestamp, generator metadata, canonical provenance, and status.
