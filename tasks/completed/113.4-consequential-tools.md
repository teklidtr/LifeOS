# Objective
Implement lifecycle transitions for proposals requested by tools safely.

# Scope
- Expose a tool to request explicit lifecycle operations (e.g., submitting a draft for review).
- Enforce the consequential operation authorization boundary.
- Reject requests to bypass explicit user approval or automatically apply proposals.

# Completion evidence

- Submit, approve, and apply requests expose only `proposal_id`.
- A trusted authorizer supplies the actor identity for every consequential action.
- Review digests are computed and verified by LifeOS rather than accepted from agents.
- MCP schemas set `additionalProperties: false` and reject extra agent-controlled fields.
- Recovery-required application failures map to a dedicated sanitized facade error.
- Placeholder tests and broad facade exception handling were removed.
