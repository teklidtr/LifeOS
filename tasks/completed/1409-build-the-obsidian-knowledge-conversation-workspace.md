# Goal

Add graphical evidence-first workspace state, entry points, scope controls, cards, citations, branches, recovery states, and accessibility.

# Scope

- Implement only this task's named capability and its focused tests.
- Preserve canonical Markdown, proposal gating, provider neutrality, and UI-first behavior.
- Record diagnostics and degraded states instead of inventing evidence.

# Out of scope

- Cloud accounts or a hosted vector database.
- Provider-specific canonical fields or hidden reasoning storage.
- Silent changes to notes outside conversation artifacts.

# Required invariants

- Markdown remains canonical and human-readable.
- Derived retrieval state can be deleted and rebuilt.
- Protected scopes fail closed before retrieval and provider calls.
- Exact evidence provenance remains inspectable.
- Consequential changes use proposals.

# Required tests

- Deterministic happy path and degraded behavior for this task.
- Malformed, stale, duplicate, sparse, and bounded-input cases where applicable.
- Provider-neutral or no-provider behavior where applicable.

# Acceptance criteria

- Focused Python and/or plugin tests pass.
- Relevant schema, protocol, type, lint, and build checks pass.
- Task documentation and implementation remain synchronized.

# Validation commands

```bash
PYTHONPATH=src python3 -m pytest --import-mode=importlib tests/retrieval tests/conversations -q
npm --prefix packages/obsidian-plugin test
npm --prefix packages/obsidian-plugin run typecheck
git diff --check
```

# Relevant design decisions

- DD-001: Markdown remains canonical
- DD-003: Durable proposal mode
- DD-013: Indexes are generated by scripts
- DD-018: Graphify is a helper, not authority
- DD-036: Obsidian is the primary interface and Python is the sole business-rule engine
- DD-060 through DD-066: semantic retrieval and conversation boundaries
