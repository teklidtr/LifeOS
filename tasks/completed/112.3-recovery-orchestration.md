# Objective
Recover interrupted applications deterministically and expose recovery-required
state safely through the facade and MCP boundary.

# Scope
* provider-independent recovery service
* phase-aware rollback or roll-forward
* idempotent recovery
* recovery invoked before a new apply
* apply and recovery cannot run concurrently
* proposal, ownership, and target consistency verification
* narrow domain recovery errors
* facade error mapping
* static sanitized MCP error mapping
* process-restart integration test
* one MCP-facing test proving unresolved recovery blocks apply

# Non-goals
* agent-controlled recovery decisions
* default allow-all recovery
* new MCP recovery tool unless separately approved
* SQLite index refresh
* embedded AI orchestration
* power-loss durability claims
