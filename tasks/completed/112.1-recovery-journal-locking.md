# Objective
Implement provider-independent recovery primitives without modifying proposal
application behavior.

# Scope
* canonical recovery-state location under local LifeOS runtime state
* deterministic transaction IDs
* versioned journal schema
* transaction phase enum
* deterministic JSON serialization
* journal creation, loading, validation, and discovery
* vault-relative and transaction-relative paths only
* rejection of absolute paths and parent traversal
* schema-version rejection
* corrupt journal rejection
* symlink-containment validation
* local POSIX apply/recovery lock
* stale process-lock behavior
* unresolved-transaction detection

# Non-goals
* changing `apply_proposal`
* installing target files
* updating generated ownership
* transitioning proposals to applied
* facade or MCP changes
* SQLite indexing
* power-loss durability claims
